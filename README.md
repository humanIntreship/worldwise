# WorldWise 🌍

A travel tracking app built with React, based on Jonas Schmedtmann's WorldWise project, with a custom authentication system including login, signup, logout, and user management.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the React app:

```bash
npm run dev
```

Run the JSON Server:

```bash
npm run server
```

> **Note:** Both `npm run dev` and `npm run server` must be running at the same time for the application to work correctly.
